# 空间分布分析结论

数据：Weibo-COV 带地理标签推文 all-geo.csv.tar.gz，入库 45,901,994 行 / 12 分片（data/cov_geo_parquet）
脚本：scripts/60_geo_analysis.py（Spark 聚合）、61_geo_daily_total.py、62_geo_share.py、70_figures_geo.py
图表由 `scripts/70_figures_geo.py` 生成到 `output/figures/`，该目录不进入版本库。

## 1. 坐标有效性与覆盖范围

- 45,901,994 行全部解析出合法经纬度（geo 子集按「带地理标签」筛选，无缺失）
- 落在中国境内（经度 73–136、纬度 3–54）的推文 44,626,472 条，占 97.22%；境外 2.78%
- 覆盖窗口 2019-12-01 ~ 2020-04-30，共 152 天

## 2. 空间热点（0.25° 网格）

首位网格为上海（121.50, 31.25）694,349 条 / 200,967 人，其后依次为
北京（116.50, 40.00）609,752、南京（118.75, 32.00）581,987、杭州（120.25, 30.25）537,651、
西安（109.00, 34.25）528,014、苏州（120.00, 31.75）507,477、深圳（114.00, 22.50）411,614。
东部沿海 + 省会城市高度聚集，与人口和互联网活跃度分布一致。

## 3. 省份维度（口径：用户资料 province，非坐标反查）

推文量前五：广东 4,858,497、北京 3,692,513、山东 3,116,762、浙江 2,800,318、江苏 2,529,725。

平均转发量与人口规模没有直接关系：北京 1.37、上海 1.28、湖北 0.99 显著高于
广东 0.25、山东 0.15、河北 0.13。一线城市用户的发言更容易被转发。

## 4. 按日归一化

省份逐日绝对量会受采集量整体增长影响。湖北推文量最高的 5 天是 2020-04-08 / 04-19 /
04-04 / 04-25 / 04-26，均落在 4 月，封城期不在前五。

数据集采集量随时间整体增长：全量逐日总量从 2019-12-01 的 191,363 条涨到
2020-04-19 的 589,588 条（最高），期间增长约 3 倍。绝对量的上升是采集节奏造成的。

按「省份占当日全量的比例」归一化后，结果如下：

| 省份 | 前 7 日占比 | 末 7 日占比 | 占比最高的一天 |
| --- | --- | --- | --- |
| 湖北 | 2.88% | 2.66% | 2020-02-15 (4.28%) |
| 海外 | 4.92% | 3.48% | 2019-12-26 (6.06%) |
| 广东 | 8.37% | 11.26% | 2020-04-21 (11.93%) |
| 北京 | 6.05% | 8.71% | 2020-04-02 (9.28%) |
| 上海 | 3.81% | 6.24% | 2020-04-05 (6.61%) |
| 浙江 | 5.68% | 6.31% | 2020-03-15 (6.93%) |

- **湖北**：占比峰值集中在 2020-01-23（武汉封城当日，3.91%）、2020-02-11、02-12、02-15，
  即疫情暴发与封城窗口；此后回落至 2.5% 左右，与封城期发言更密集的分布相符。
- **海外**：占比峰值在 2019-12-25 ~ 12-28 与 2020-01-02（圣诞与元旦假期），随后持续下降。
- **广东 / 北京 / 上海**：占比整体上升，后半程成为讨论主力。
- **北京**的次高点是 2020-02-06（李文亮事件次日，9.14%）。

## 5. 口径说明

- 「境内占 97.22%」按坐标判定；「省份推文量」按用户资料省份判定，两者口径不同，不能混用。
- 用户资料省份是采集时的静态字段，不随发帖时间变化；坐标是发帖时的动态定位。
- 数据集按 179 个疫情关键词筛选，非疫情内容的缺失会使占比曲线偏向疫情相关内容。
